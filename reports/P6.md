## 交付

### 1. operator_artwork（24 工具，IMAGES_ENABLED=false → 23）

- 注册与 TS server-core 同门：`registry_for(images_enabled)` 仅在开关开时挂 artwork；tools/list 顺序 prts→gamedata→story→artwork（差分转绿证明）。
- 输出：`ToolOutcome` 增 image block——**所有通道 text 块后保留 image**；structured 通道文本为摘要、另附 structuredContent（renderImageResult 语义）。base64 标准 RFC4648 自实现（0..255 全字节向量单测钉死）。
- 参数面：operator_name 必填、action 必填 enum（list/get）、artwork_id optional string（null 拒绝）、variant optional enum（original/large/preview，null 拒绝）；`action=get 无 token` 在任何后端工作前拒绝。

### 2. local 后端（LOCAL_IMAGE=true）

- 表单别名：`ARTWORK_FORM_CHAR_IDS`（阿米娅(近卫)/(医疗)），全/半角括号归一后精确表单身份；跨形态 token 归属拒绝（半角/全角请求差分各一）。
- index 解析复用 P2 `parse_index`（frozen akdp-images/v1）；label 三级（displaySkin.skinName→`时装（theme）` 占位→`#N` 程序化/`+` 变体）；skin_table 经每代 dataset 缓存（失配回退空表）。
- list：charIdOf 归属过滤 + compareIds 排序 + skin_group/acquisition/description 有界元数据；get：变体缺失（可用清单提示）/realpath **双解析包含守卫**（symlink 逃逸拒绝——单测构造逃逸 symlink 验证）。
- 无代目录/无 index → 统一"立绘数据未就绪"文案；干员未找到 → search_prts 建议。

### 3. MediaWiki 后端（LOCAL_IMAGE=false）

- list：allimages 前缀分页（≤50 页、continue 参数原位合并）+ CharinfoV2 parsetree 标签 join（`时装N名称`）；文件名解析（skinN→时装、`Nb` 建筑小人剔除、`(形态)` 括号后缀）；compareIds 排序。
- get：imageinfo（large=1024/preview=256 的 iiurlwidth 精确参数集回放钉死）→ download_image_safe：HTTPS+host=media.prts.wiki+重定向终 URL 复查+MIME 三类+**HTTP body 字节 1MiB 上限**+PNG/JPEG/WebP magic；错误前缀 `下载图片失败：`。
- 256MiB LRU 字节缓存（PRTS_IMAGE_CACHE=false 关闭；命中提升/超限淘汰/自逐出单测）；original 一律拒绝（1MiB 上限理由文案）。

### 4. 完整图片同步链（src/sync/images_sync.rs）

发现（images- 前缀 latest、排除 baseline 前缀）→ tag 捷径（currentVersion+分片集相同则零下载）→ index.json 下载与 schema 校验 → **index 权威 currentVersion 对账**（与发现 tag 漂移 fail-closed）→ delta 链枚举（定宽版本字典序、重复版本 fail-closed、首屏 100 release 不足时翻页至链首覆盖）→ **缺 delta 资产在 baseline 下载前快速失败** → 重建（baseline 4/6 分片按 ORIGINAL_IMAGE，或 fast path：同 baseline 同分片且不超前时复制前代+仅增量 delta）→ **逐文件 sha256 校验**（文件缺失即失配；任一失配抛错不激活）→ 权威 index.json 字节直写 + 代级 meta → 原子激活 → 顶层 meta（generation_root）→ 24h 代际清理；全程 `.images.lock`（P2 目录租约协议复用）；失败路径：staging 清理、offline_fallback 保留旧代。
