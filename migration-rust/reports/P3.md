## 关键保真点（docs/03 "必须保留"清单）

- **干员与 trap 同名冲突优先级**：name→charId 只收 `char_` 前缀（fixture 反案 + 单测）。
- **稀有度/职业/定位 raw/label 配对**：payload 双字段，渲染用 label。
- **天赋槽与候选**：`？？？` 占位候选跳过；headline=最后候选；档位注记去重（首条"解锁"、其余"强化"）+ 潜在 `潜能N档强化`。
- **基建技能按槽位最高条件**：phaseRank 比较（PHASE_N 解析，坏值 -1）。
- **技能每等级/专精标签/blackboard**：`""`/`0`/`0.0`/`0%`/`0.0%` 五种格式、`-` 前缀取反（仅数值）、valueStr 字符串孪生、0 值渲染 "0"、`ABILITY_RANGE_FORWARD_EXTEND` 无 blackboard 键保持字面、被动 spType 整数 8 → 空串、duration -1 不渲染。
- **属性关键帧插值**：线性 + half-away（整帧对取 0 位截断、含小数帧 2 位）、退化 span/非数值取上帧、满信赖非零字段、潜能描述数组；`-0` 归一。
- **enemy m_defined/m_value 合并和 level0 投影**：`{m_defined:false}` 跳过、`true` 替换、递归合并；level0 缺失取升序首键（JS 整数键序）；legacy `{enemies:[{Key,Value}]}` 与 AKDP 直映射双形。
- **关卡覆盖、不同变体、掉落及物品排序**：SPAWN/actionType 0 计数（count 至少 1）、level `"bad"`→0、覆写名（name/prefabKey m_value）、sortId+compareIds（UTF-16）、物品 sortId+compareIds tie-break。
- **enemyStats.pythonFloatString**：按 docs/03 保留为领域格式器（`10.0` 尾缀、千分位 `\B(?=(\d{3})+(?!\d))` 正则语义逐字符实现）。
- **消息族**：excel/levels missing 文案（静态同步目标路径）、各加载器文件不存在文案（含 resolveForDiagnostics 绝对路径）、`未找到干员/敌人/物品/关卡` 族、`读取关卡敌人失败：` 仅包裹 throw（`未找到关卡`/level 文件串是裸 return）——由差分钉死。
- **排序语义分离**：compareIds（UTF-16 码元序）用于 id 列表；stageEnemy 计数并列用 ICU localeCompare（`locale_compare`，15 探针）——docs/02 预告的排序碰撞案例已验证。
