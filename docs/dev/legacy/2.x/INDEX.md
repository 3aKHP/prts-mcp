# 2.x historical documentation

These documents and ops examples are archived context captured before the Rust root import. They are not the active development/install instructions for 3.x; their relative paths describe the old repository layout and may refer to removed source directories. Historical versions and code remain available at fixed Git tags.

For maintained legacy documentation, use [lts/2.8](https://github.com/3aKHP/prts-mcp/tree/lts/2.8) or [lts/1.7](https://github.com/3aKHP/prts-mcp/tree/lts/1.7). The old roadmap candidates are deferred until after 3.0, not promised as 2.9 work. Current 3.x rules live at the repository root and docs/dev/; see [STATUS](../../../../STATUS.md).

Archived agent instructions use AGENTS.original.md and CLAUDE.original.md so an agent visiting historical documents does not automatically apply obsolete runtime or branch instructions. The active governance files remain at repository root.
