# ADR-0023：Wiki 立绘下载大小上限

- 状态：Accepted
- 决策日期：2026-11-08
- 关联：[Issue #339](https://github.com/3aKHP/prts-mcp/issues/339)、[兼容性基线](../../../contracts/baseline.json)

## 背景与问题

旧实现沿用的 1 MiB 下载上限会拒绝正常的 1024px PNG。报告中的佩佩时装缩图为 2,286,778 字节，影响 `large` 变体使用。维护者批准提高默认上限并允许配置，采用最小修复。

## 决定

默认上限提高为 8 MiB，通过环境变量或 TOML 的 `PRTS_MAX_IMAGE_BYTES` 设置正整数字节数，修改后重启生效。上限按 HTTP 解压后的响应体计数；保留现有下载校验和图片原始字节，不增加转码、自动缩图或配置热重载。Wiki 模式仍不提供 `original`，拒绝提示删除固定 1 MiB 理由。

## 后果与验证

较大的图片会增加下载及 Base64 响应的内存和传输成本，部署者可调低上限。新行为登记为 D-008。冻结差分显式使用旧上限，保留历史 golden，仅对原图拒绝提示做精确预期适配；新增测试覆盖新默认值、配置优先级、大小边界及 gzip 解压后超限。
