# ADR-0021：兼容增量的管理 CLI 与配置文件

- 状态：Accepted
- 决策日期：2026-11-02
- 关联：[ADR-0003](ADR-0003-management-cli-scope.md)、[ADR-0020](ADR-0020-pypi-native-wheels.md)、[CLI 手册](../../admin/cli.md)、[Issue #292](https://github.com/3aKHP/prts-mcp/issues/292)、[Issue #314](https://github.com/3aKHP/prts-mcp/issues/314)

## 背景与问题

Rust 迁移已完成，PyPI 原生候选需要帮助与版本入口。维护者希望一期同时覆盖常用配置、诊断和数据管理操作，并按兼容增量 Patch 交付，优先安排在 3.2.2。ADR-0003 保留的设计储备不再只用于最小帮助功能。

## 备选方案

- 按操作系统改变参数语法：不采用。同一平台可能使用多个 Shell，MCP 客户端也可以直接创建进程；参数列表必须保持相同含义。
- 将既有服务器改名为 `prtsd` 并加入后台实例管理：保留为后续议题。一期不迁移已有启动命令，不实现守护进程或在线控制通道。
- 在旧入口自动读取新配置文件：不采用。安装新版本或创建用户配置文件不应悄悄改变旧部署。
- 新增 `prtsctl`，由 Rust 共享配置和同步能力：采用。通过补全、路径规则、文档示例与实际 Shell 验证适配平台。

## 决定

`prtsctl` 无参数显示帮助，提供 `serve`、`config show/validate/init/set/unset`、`doctor`、`data status/sync/verify` 与补全。`serve` 留在当前进程，各渠道默认 HTTP；stdio 可由显式参数、环境变量或文件选择。现有入口保留默认传输和环境变量语义，只新增帮助、版本和显式 `--config`。

配置采用单个版本化 TOML 文件，优先级为显式参数、环境变量、文件、默认值。新字段严格校验，环境变量继续按既有规则解析。只有 `prtsctl` 自动读取固定用户级文件；不搜索当前目录或自动加载 `.env`。文件相对路径基于文件所在目录。配置编辑使用锁和原子替换，保留注释，dry-run 不写入。令牌不通过 `config set` 写入，所有报告脱敏。

管理输出采用文本和 JSON，`--output` / `-o` 不影响 MCP 工具输出通道。JSON 是脚本接口，字段类型、枚举与退出码受兼容承诺约束。只读命令在服务器初始化前分流；完整校验与联网探测必须由用户显式调用。离线数据观察不代表运行中实例状态。

一次性同步复用既有源归属、锁、摘要、代际激活与恢复规则。调用级锁等待预算不改变后台调度默认值。取消中断网络等待，已进入的发布临界区允许安全完成。图片同步须显式选择，不覆盖自定义只读数据。

## 后果

管理员可通过一个入口完成配置到启动的常用流程，原有 MCP 客户端配置继续有效。PowerShell 可以通过 `ConvertFrom-Json` 消费管理结果，无须额外 PowerShell 业务实现。

新增配置与机器输出形成需要长期维护的公开接口。实现按配置路径重构、CLI 主体、分发接入拆分 Standard PR，并对整体执行 Huge 级别审查。发版前须验证五平台入口、安装包、进程生命周期和旧环境行为。CLI 就绪后重新生成 PyPI 候选，正式上传仍属于后续统一发版流程。
