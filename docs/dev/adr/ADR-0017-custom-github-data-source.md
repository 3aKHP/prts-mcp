# ADR-0017：自定义 GitHub 数据源与目录归属

- 状态：Accepted
- 决策日期：2026-10-29
- 关联：[#288](https://github.com/3aKHP/prts-mcp/issues/288)、[ADR-0016](ADR-0016-self-hosted-object-storage-data-source.md)、[数据同步说明](../../admin/data-and-sync.md#自定义-github-数据源)

## 背景

数据与图片同步此前使用固定的 AKDP 仓库。兼容数据源的部署需求，以及图片基线实验对独立源仓库的需求，都要求消费者能配置 GitHub 仓库身份。现有缓存快捷判断使用版本号、分片集合或摘要，不能据此判断两个仓库属于同一条发布链。

## 决策

新增 `PRTS_DATA_SOURCE_REPO`，以 `owner/repo` 指定数据与图片自动同步的 GitHub 仓库。空值使用 `3aKHP/arknights-data-pipeline`；非法配置在启动时拒绝。仓库身份不区分大小写，显式指定默认仓库与未设置配置等价。配置只在启动时解析，所有同步入口和手工构造的资产地址使用同一来源对象。

自定义源默认使用原数据根下的 `sources/<owner>/<repo>/`，不迁移默认源缓存。为保证跨平台目录身份一致，Windows 设备名（如 `con`、`com1.zip`）及以点结尾的组件，在所有平台均编码为 `~` 加小写 ASCII 十六进制。显式同步路径保持优先，但首次接入自定义源时必须为空；来源标记记录 schema 版本和仓库身份，通过目录锁与原子写入建立。非空未标记目录、不同来源和损坏标记均拒绝接管。启动检查在数据读取初始化之前完成，同步写入前再次检查。默认源兼容原有未标记目录，不补写标记，也不能接管自定义源目录。

自定义本地只读输入保持既有行为，不纳入自动同步目录绑定。内置备用数据的规则保持不变：自定义源首次同步前仍可能使用发行包内的默认源 JSON 数据。切换源不构成所有返回数据都来自该仓库的保证。

自定义源表示部署者显式离开默认受管血缘，信任其提供的兼容产物。过渡期保持现有 SHA-256 与 TLS 校验，不降低默认源的校验要求；来源标记用于本地一致性，不是发布者认证。发布签名由 [#287](https://github.com/3aKHP/prts-mcp/issues/287) 另行交付，届时自定义源升级为钉公钥或显式降级的信任策略。

配置族谱固定为 `PRTS_DATA_SOURCE_REPO`（GitHub 仓库）、`PRTS_DATA_SOURCE_BASE`（对象存储地址，ADR-0016 预留）与 `PRTS_DATA_SOURCE_PUBKEY`（签名公钥配置，签名轨道预留）。本次仅实现 `REPO`，不启用另外两个变量。

## 后果

默认部署可无配置升级；自定义源不借用另一仓库的版本号或缓存，代价是首次同步需要独立磁盘空间和下载。本期不提供原目录跨源迁移，不调整镜像顺序、图片激活语义或 LTS 线。实验仓库的写权限隔离仍由发布凭据及仓库权限保证，消费者配置不能替代该边界。
