## 共享索引：身份、换包、释放（docs/07 P4 完成条件）

- **身份**：descriptor = `zip:{path}:{size}:{mtime_ns}`（TS 同式）。缓存为进程级单例——**索引属于数据集，不属于会话**（docs/03）；多会话共享一份。
- **换包重新构建一次**：`swap_rebuilds_once_and_reads_new_content`——同一进程内原子替换 zip 后，下一次调用恰好重建一次（构建计数 +1），内容切换立即可见，无需重启；再次调用命中缓存（同一 Arc）。bench `rust-swap`：换最小包重建 28ms（复用 2.4ms）、换回全量 1929ms（恰一次）、第三次 32ms；VmHWM 稳定 111MB。
- **旧索引释放**：`drop` 语义单元断言（在途读者持有旧 Arc，结束后无引用）；bench 换包后 RSS 110.7→104.3MB（大索引释放）。交替重建后的 RSS 高位是 glibc 已释放页保留（malloc 不归还 OS），非索引滞留——构建计数与 Arc 断言排除泄漏。
- **单飞共享**：`concurrent_first_calls_share_one_build`——4 线程同时冷启动，构建计数恰 +1。bench `rust-share`：两会话并发冷查询，B 等待 A 在途构建（wall = 1.13× 单次冷构建 + 50ms 错峰），不产生第二份索引。

## 冷/热性能测量（artifacts/p4-bench.json，真实 2357 条目 zip）

| 腿 | Rust | TS（bun） |
|---|---|---|
| 冷（首建全索引，独立进程） | p50 **1828ms**（n=5，p95 2014ms），峰值 RSS **108.4MB** | p50 1216ms（n=3），峰值 RSS 427.3MB |
| 热（已建索引） | p50 **2.7ms** / p95 4.1ms（n=100） | p50 4.0ms / p95 7.5ms（n=30） |
| 换包（→最小包/→全量包） | 28ms / 1929ms，恰一次重建，随后 2-3ms | —（结构同为描述符缓存） |

诚实记录：Rust 冷构建比 bun 慢约 0.6s（serde_json Value 全量解析 2357 章节 vs JSC JSON.parse + JIT；无持续无界增长，见上）。热查询与内存显著占优（2.7ms vs 4.0ms；108MB vs 427MB 峰值）。冷构建优化（零拷贝行提取）留作后续迭代，不影响正确性验收。
