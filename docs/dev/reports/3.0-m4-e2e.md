## 4. 真实问题、处置与披露

1. 事故 A（执行失误，已处置）：12:47 本地时间以 `--version` 试探候选二进制，该参数不受支持导致服务器以默认配置启动并从真实 GitHub 完成启动同步（44.2MiB 计费流量）。进程已终止。副作用：用户默认数据目录 `~/.local/share/prts-mcp` 的 storyjson 已完整更新至 26-10-08-r2；excel 新代际已解压但 pair pointer 仍指向旧 26-08-07 代际（levels 未下载即被终止），处于待完成成对更新状态，当前完全可读、无损坏。后续所有启动均经隔离封装。
2. 事故 B（脚本缺陷，已修复）：任务脚本首版遗漏六个代理变量覆盖，交互 shell 导出的真实 Clash 代理（172.30.176.1:7897）被子进程继承，导致一轮受控测试实际走公网完成三 ZIP 同步（57.8MiB ZIP 本体，目标为测试目录，已删除）。修复后以 `/proc/<pid>/environ` 核验并复测：真实源在 127.0.0.1:9 立即失败、仅镜像可达。两次事故 ZIP 本体合计 106,914,425 B（约 102.0 MiB）；实际账单还可能包含 API/协议开销，不能当作全部收费流量。均如实记录，不并入任何"通过"证据。
3. 观测（验收纠正）：残留进程可在终止 /home/asus/.volta/bin/node 外层 Volta 启动器时复现；它不是实际 Node/npm 垫片进程。改用 process.execPath 指向的实际 Node 启动已发布 npm 垫片后，向该 PID 发送 SIGTERM，Rust 子进程退出且 HTTP 端口关闭。不能把 Volta 的外层进程行为登记为本产品“Linux npm 不转发 SIGTERM”。证据见 §6。
4. 修复需求：无。未发现迁移阻断，未产生源码修复 PR；alpha.3 无需因本轮结果重发。
