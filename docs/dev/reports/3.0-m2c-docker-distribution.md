日期：2026-10-13。PR：[#232](https://github.com/3aKHP/prts-mcp/pull/232)。实现检查点：57c7336b7a5b5b191b42be182b3444fc3d0cc539；后续收尾更新仅补充文档，最终合并以 PR 最终 HEAD 的五平台 native/npm、双架构 Docker、完整 CI 和独立复审为准。

## 已完成

发行 Dockerfile 使用同版原生 payload 和精确固定、校验过的备用数据，独立暂存构建上下文；不复制开发者根 data/ 或缓存。入口核对原生 host/daemon CPU、当前 clean BUILD、BUNDLE 版本与当前数据 pin，严格核对全部文件集合与哈希、实际原始许可，拒绝链接、特殊文件、清单外文件和重复记录。[包装规则与复现步骤](../DOCKER-DISTRIBUTION.md)。

镜像固定 Ubuntu 24.04 base digest，包含原生 Rust/C 程序、只读备用数据、ca-certificates 和 tini，没有 JS/TS/Python 业务运行时或编译器。tini 为 PID 1，转发进程组信号；docker stop 实际退出 143，无需等到强制 SIGKILL，不认领应用层 graceful shutdown。OS 包按构建时仓库安装，不能承诺 bit-for-bit 重建。

GHCR profile 延续 root（0:0）和默认 stdio，只有明确选择 PRTS_TRANSPORT=http 才使用 HTTP，默认 PORT=3000。整 /data 挂载保存 pair pointer；四个旧子目录挂载继续按 extract_meta 读取，重建后无需转换格式。可选非 root /只读根文件系统需要可写数据目录，四个分离挂载另需可写 /data 父目录 tmpfs。没有自动 chown 或用户数据迁移。

本机 x64 同检查点归档加载及 10 项检查通过。完整 Rust 验证通过 fmt/clippy、215 项测试、384/384 冻结差分（0 failed/blocked）、生命周期和 3,276 个原生正则 ASAN 案例；本 PR 无 Rust 业务或依赖变化。
